MOQ Catalog Validator

Checks a MOQ catalog against the MSF and CMSF drafts: it identifies the streaming format, draft version and media packaging in use, then reports missing required fields, values that break the specification and fields that belong to a different draft, each linked to the section that defines it.

Supported: MSF draft-00 / draft-01, CMSF draft-00 / draft-01 — packaging LOC, CMAF, LOCMAF, M2TS, plus mediatimeline, eventtimeline, moqlog and moqmetrics.
